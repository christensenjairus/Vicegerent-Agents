# Apply order for the patches/ scripts, consumed by the Dockerfile's single
# patch-runner layer. One filename per line; blank lines and full-line comments
# are ignored. The Dockerfile fails the build if a patches/[0-9]*.py file is
# missing from this list, so adding a patch means adding a line here.
#
# Order is LOAD-BEARING and is NOT plain numeric order:
#
#   0019 runs first. It deletes mnemosyne-memory's stray site-packages/tools/
#   namespace-package directory, which otherwise shadows Hermes' real `tools`
#   package. Every patch that locates its target via
#   importlib.util.find_spec("tools.<mod>") -- 0008, 0011, 0012, 0018, 0022,
#   0023, 0027 -- would resolve against the wrong `tools` without it.
#
#   0016 and 0020 must follow 0014 (they import helpers it adds).
#   0039 must follow 0028 and 0036 (it rewrites their shared call site).
#
#   0043 runs after every pricing-affecting patch. It is the single source of
#   truth for model prices and
#   emits them into BOTH price sinks (agent/usage_pricing.py and
#   agentburn/prices.py). It imports agent.usage_pricing to compare its table
#   against upstream's and fails the build on a rate conflict, so it must see
#   the module in its final post-patch state. It also supersedes the deleted
#   0038 (GLM prices + zai billing route, folded in) and the price half of
#   0004 (which is now HERMES_HOME-only).
#
